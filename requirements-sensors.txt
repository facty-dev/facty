# design) — the sensors run on the host or CI (GitHub Actions), or baked

# when these are missing.
#
#   make deps-sensors        # uv venv + install

# The label sensor (zero-shot NLI classification, CPU-only):
#   onnxruntime      — inference (fp32 + int8 ONNX variants, measured
#                      4.9–7.1s per 600 pairs on a 2–4 vCPU budget)
#   transformers<5   — tokenizer only. PINNED: transformers 5.x mis-loads
#                      the NLI checkpoints' classification heads (missing
#                      keys → randomly initialized head → garbage labels)
onnxruntime
transformers<5
