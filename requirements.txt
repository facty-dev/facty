# Facty — Python dependencies (the optional DX layer).
#
# The engine core (engine/engine.py) and the CLI control plane
# (engine/cli.py) are dependency-free — they run anywhere, including the
# gondolin VM snapshot (no pip guarantees there). The ONE dependency is
# Textual, the TUI framework behind the primary interface (the `facty`
# workbench: bare `./facty` or `./facty tui`).
#
# Latest available, per PO 2026-10-17 — refresh with:
#
#   make deps                              # uv venv + install
#   uv pip install -U -r requirements.txt  # upgrade to latest
#
# Note: the latest Textual requires a modern Python (check its
# requires-python on install). The venv from `make deps` uses uv's
# managed Python, not the host's system python3.
#
# The optional sensors (engine/label.py) live in requirements-sensors.txt
# (`make deps-sensors`) — onnxruntime is heavy-ish and host/CI-only, never
# in the gondolin VM snapshot.
textual
pyte  # terminal emulator for the embedded pi TUI (TerminalPane)
